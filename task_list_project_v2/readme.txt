Hello! This is my command-line task manager project, created as part of my Python course on Udemy. This simple application uses SQLite to store the tasks you create, modify, or delete.

-----------------------------------------------------------

Features:


Easily add tasks, which are automatically marked as "unfinished"

Delete tasks you no longer need, with confirmation to prevent mistakes

View all your tasks and their status (finished or unfinished)

View only the tasks that remain to be done

Change the status of tasks to mark them as finished or unfinished

All data is stored locally in a SQLite database

-----------------------------------------------------------

Installation and Running:


Requirements: Python 3.6 or higher
No additional installation is needed; it uses only Python's standard library.

To run the project on your machine:

Clone this repository with git clone https://github.com/yourusername/task-manager.git
Navigate to the created folder: cd task-manager
Start the application: python main.py

-----------------------------------------------------------

Quick Usage:


Once started, a menu presents the main options:

Add a task

Delete a task

View all tasks

View unfinished tasks

Change a task's status

Quit

This way, you can create your task list, modify statuses, and manage priorities easily.
